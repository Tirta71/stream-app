# CHILL App

Monorepo untuk aplikasi CHILL.

## Struktur

```txt
stream-app/
├── frontend/
│   ├── src/
│   ├── public/
│   └── package.json
├── backend/
│   ├── prisma/
│   ├── src/
│   └── package.json
├── README.md
└── .gitignore
```

## Frontend

```bash
cd frontend
npm install
npm run dev
```

## Backend

```bash
cd backend
npm install
npm run dev
```

Salin `.env.example` menjadi `.env` di masing-masing folder, lalu sesuaikan nilainya.
